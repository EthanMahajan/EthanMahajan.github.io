# Website refinement audit: October 20, 2026

Scope: both review branches, preserving the experimental homepage and all technical project evidence. Main and live deployment are outside this work.

## Findings and changes

- Repeated cards, tinted facts panels, download banners, and résumé boxes competed with the work. Shared styles now use typography, spacing, and restrained divider lines instead.
- Résumé contact table cells retained a dark foreground in dark mode. Explicit theme text colors correct the contrast. Dates and locations are quiet metadata; mobile entries stack and the table of contents moves to desktop widths.
- Three project columns compressed tablet layouts. The index now uses two columns on tablets and three on larger screens, with proper category and card heading hierarchy.
- Generic repeated project endings became useful next-project/all-project navigation with compact email, LinkedIn, and inline copyright links.
- CAD toolbar controls now share the site's button styling. Expandable videos, comparison captions, skill evidence, and the experimental featured section have lighter framing.
- Homepage section headings now use the same hierarchy as the rest of the portfolio. No technical descriptions, media, project evidence, or download destinations were removed.

## Verification

The audit includes home, project index, all five project pages, research, résumé, engineering notebook, and 404 across desktop, tablet, mobile, and both themes. Build and rendered-page verification are performed after these shared changes; final results are reported with delivery. Historical numerical review cycles remain in portfolio-preview.md and are not rescored here.
